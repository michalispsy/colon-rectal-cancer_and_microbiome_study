METHOD
------------------------------------------------------------------------------
For each PA species feature, a Cochran-Mantel-Haenszel test was run
using Study as the blocking/stratification variable. Each study contributes
a 2x2 table of presence/absence by group, when both groups are present.
FDR correction was performed separately within each comparison using
Benjamini-Hochberg correction.

For sparse 2x2 tables, a continuity correction is used for stable common
odds-ratio estimation. The hypothesis test remains the stratified association
test analogous to R's mantelhaen.test(presence, condition, study).
