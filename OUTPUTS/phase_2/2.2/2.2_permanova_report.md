# ΒΗΜΑ 2.2 — PERMANOVA: Ποσοτικοποίηση Πηγών Διακύμανσης

---

## Μεθοδολογία

Η **PERMANOVA** (Permutational Multivariate Analysis of Variance) χρησιμοποιήθηκε για να ποσοτικοποιήσει πόση από τη συνολική διακύμανση στα δεδομένα μικροβιώματος εξηγεί κάθε μεταβλητή. Είναι η μη-παραμετρική εκδοχή μιας MANOVA — δεν απαιτεί κανονικές κατανομές, κάτι κρίσιμο για δεδομένα μικροβιώματος.

**Παράμετροι:**
- **Input:** `X_explore.csv` (214 Hurdle-encoded features, 1.603 δείγματα μετά την αφαίρεση 1 δείγματος με missing Age)
- **Distance metric:** Euclidean πάνω σε StandardScaled features
- **Permutations:** 999 (standard στη βιβλιογραφία μικροβιώματος)

> [!WARNING]
> **Δικαιολόγηση Αφαίρεσης της Μελέτης GuptaA_2019**
> 
> Παρατηρούμε ότι η μελέτη **GuptaA_2019** παρουσιάζει ύποπτα υψηλό R² (7.72%), τριπλάσιο από τις υπόλοιπες. Αυτό οφείλεται σε ένα σοβαρό μεθοδολογικό σφάλμα της αρχικής μελέτης, το οποίο καθιστά τα δεδομένα της ακατάλληλα (heavily confounded) και οδηγεί στην **απόφασή μας να την αφαιρέσουμε** από τα επόμενα βήματα:
> 
> 1. **Geographic Separation & Confounding:** Οι ερευνητές συνέλεξαν τα 30 δείγματα CRC και τα 30 δείγματα υγιών (controls) από δύο **εντελώς διαφορετικές γεωγραφικές τοποθεσίες** στην Ινδία (Bhopal και Kerala αντίστοιχα).
> 2. **Split Datasets:** Στα δημόσια repositories (π.χ. SRA), τα δεδομένα sequencing της μελέτης είναι διαχωρισμένα σε δύο διαφορετικά BioProject accessions (PRJNA531273 και PRJNA397112).
> 3. **Technical Noise:** Ο φυσικός διαχωρισμός κατά τη συλλογή εισάγει τεράστιες συγχυτικές μεταβλητές (environmental variables, regional diets, handling procedures, DNA extraction/sequencing batches). Είναι αδύνατο να αποδειχθεί αν οι διαφορές στο μικροβίωμα οφείλονται στον καρκίνο (CRC) ή αποτελούν artifacts των διαφορετικών τοποθεσιών και μεθόδων επεξεργασίας.
> 
> Λόγω ακριβώς αυτού του limitation, οι σύγχρονοι βιοπληροφορικοί χρησιμοποιούν το dataset του Gupta 2019 κυρίως ως "stress test" benchmark για την ανάπτυξη μοντέλων που εντοπίζουν και διορθώνουν cross-study batch biases. Για την κατασκευή ενός αξιόπιστου μοντέλου πρόβλεψης, **η μελέτη αυτή θα εξαιρεθεί**.

## Ερμηνεία Αποτελεσμάτων

### 1. Study κυριαρχεί (R² = 8.59%)
- Αναμενόμενο σε cross-study microbiome δεδομένα
- Αλλά **8.6% είναι πολύ χαμηλό** σε σύγκριση με raw data χωρίς harmonization (που τυπικά δίνει 20–40%)
- Αυτό επιβεβαιώνει ότι η εναρμόνιση (curatedMetagenomicData + uniform pipeline) **δουλεύει αποτελεσματικά**

### 2. Condition effect μικρό αλλά πραγματικό (R² = 0.46%)
- Αυτό ΔΕΝ σημαίνει ότι δεν μπορούμε να ταξινομήσουμε CRC
- Σημαίνει ότι **η συνολική δομή** δεν κυριαρχείται από το CRC
- Οι Thomas et al. 2019 και Wirbel et al. 2019 αναφέρουν παρόμοια αποτελέσματα
- Ένα supervised ML model μπορεί να αξιοποιήσει τις subtle διαφορές που η PERMANOVA δεν αναδεικνύει

### 3. Gender ελάχιστο (R² = 0.19%)
- Καλό νέο για fairness: το φύλο δεν οδηγεί τη δομή
- Μειώνεται ο κίνδυνος spurious bias στο μοντέλο

### 4. Age μικρό (R² = 0.47%)
- Η ηλικία μπορεί να χρησιμεύσει ως confounder control αλλά δεν κυριαρχεί

### Τι Σημαίνει για το Pipeline

| Εύρημα | Επίπτωση |
| :--- | :--- |
| Study = 8.6% | LODO cross-validation **απαραίτητο** — δεν μπορείς να κάνεις random split |
| Condition = 0.46% (σημαντικό) | Supervised ML θα λειτουργήσει — αλλά χρειάζεται σωστά features (hurdle encoding ✓) |
| Condition σημαντικό σε 7/11 studies | Ανεξάρτητη επιβεβαίωση ότι το signal δεν είναι batch artifact |
| Gender = 0.19% | Fairness-aware modeling δεν θα "χαλάσει" τη δομή |
