STEP 3.4 — VISUALIZATION
================================================================================

Purpose
-------
This script creates visualization-oriented summaries for Phase 3 differential abundance analysis.
It is self-contained and uses only X_explore.csv and metadata.csv.

Important note
--------------
The volcano plots in this script use simple visualization statistics:
  - rCLR: mean rCLR difference with Mann-Whitney p-values
  - PA: prevalence difference with Fisher exact p-values
They are useful for plotting and biological orientation, but the formal evidence should come
from the blocked Wilcoxon, CMH, and random-effects meta-analysis scripts.

Recommended interpretation
--------------------------
Use these plots to visually summarize Phase 3 and to select candidate species for comparison
with SHAP features in Phase 5. Do not use this visualization-only script as the sole
basis for statistical claims; rely on the formal blocked and meta-analysis scripts for that.
